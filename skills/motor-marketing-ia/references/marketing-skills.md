# Referencia — Skills de marketing (el cerebro estratégico)

El estratega del equipo. Estos skills le dan al Motor de Marketing IA criterio real, no
solo capacidad de ejecutar. Invócalos por nombre según la tarea.

**Instalación (un comando, 45 skills):** `npx skills add coreyhaines31/marketingskills`.
El anti-slop (`stop-slop`) viene aparte con el pack `anthropic-skills`.

## Los que más usarás

| Skill | Cuándo |
|---|---|
| **marketing-ideas** | El dueño está perdido: "no sé cómo promocionar esto". Punto de partida. |
| **ads** | Estrategia de campaña: objetivo, público, presupuesto, bidding (antes de tocar Meta Ads). |
| **ad-creative** | Generar/iterar muchas variantes de copy de anuncios a escala. |
| **copywriting** | Copy de páginas, headlines, CTAs, captions, guiones. |
| **stop-slop** | **Obligatorio:** pasa TODO el texto por aquí para que no suene a IA. |
| **cro** | Optimizar una landing/página que no convierte. |
| **social** | Estrategia y contenido de redes (feed, reels, calendario). |
| **emails** | Secuencias de nurture, bienvenida, re-engagement. |
| **content-strategy** | Decidir qué contenido crear (pilares, clusters, calendario). |
| **marketing-psychology** | Aplicar principios de persuasión/sesgos a una pieza. |
| **customer-research** | Entender al cliente del cliente antes de escribir. |

> El pack trae más de los listados (seo-audit, launch, referrals, pricing, offers,
> sms, cold-email, aso, analytics, etc.) — úsalos cuando la tarea lo pida.

## Regla de oro
El flujo estratégico casi siempre es:
**`marketing-ideas`/`ads` (qué hacer)** → **`copywriting`/`ad-creative` (decirlo)** →
**`stop-slop` (que no suene a robot)** → ejecución con las herramientas de producción.

Nunca ejecutes pauta o contenido sin haber pasado por la capa estratégica y por
`stop-slop`. La diferencia entre "IA que hace ruido" y "un departamento de marketing"
es justamente este criterio.
